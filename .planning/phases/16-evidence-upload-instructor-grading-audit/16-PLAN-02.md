  <name>Task 1: Implement DELETE /api/evidence/[id] route handler and tests</name>
  <files>src/app/api/evidence/[id]/route.ts, tests/evidence-grading.test.ts</files>
  <action>
    - Open `src/app/api/evidence/[id]/route.ts` and add a `DELETE` request handler.
      - Authenticate using `requireApiAuthPolicy(req, { sameOrigin: true })`.
      - Retrieve the evidence record by its `id` param. If it does not exist, return `404 Not Found` with `{ error: "Evidence not found" }`.
      - Validate ownership:
        - The current user must be the owner of the evidence (`evidence.userId === user.id`) or have the role `"ADMIN"`.
        - If not, return `403 Forbidden` with `{ error: "Forbidden" }`.
      - Check if the evidence has already been graded:
        - If `evidence.rating !== null`, return `400 Bad Request` with `{ error: "Cannot delete graded evidence" }`.
      - Physical file cleanup:
        - Extract the filename using `path.basename(evidence.fileUrl)`.
        - Construct the disk path using `path.join(process.cwd(), "uploads", "evidence", filename)`.
        - Call `fs.promises.unlink(filePath)` to delete the physical file. Wrap this in a try-catch to ensure that if the file is missing from disk, the DB deletion still proceeds.
      - Delete the database record using `prisma.evidence.delete`.
      - Write security audit log trace:
        - `writeSecurityAuditLog(prisma, { userId: user.id, action: "DELETE_EVIDENCE", entity: "EVIDENCE", entityId: evidence.id, metadata: { title: evidence.title } })`.
      - Return a `200 OK` or `204 No Content` response (e.g. `{ success: true }`).
    - Open `tests/evidence-grading.test.ts` and add unit/integration tests for the `DELETE` handler:
      - Reject unauthorized users or wrong owner.
      - Reject deletion if the evidence has a rating (is graded).
      - Successfully delete ungraded evidence, verify DB delete call and fs unlink call (mocked).
  </action>
