<task type="auto">
  <name>Task 2: Implement secure gated file streaming endpoint and tests</name>
  <files>src/app/api/evidence/[id]/file/route.ts, tests/evidence-gated-file.test.ts</files>
  <action>
    - Create `src/app/api/evidence/[id]/file/route.ts` implementing a `GET` request handler (per D-02).
      - Authenticate using `requireApiAuthPolicy(req, { sameOrigin: true })`. If not ok, return `policy.response`.
      - Query `prisma.evidence` for the record matching the `id` param. If missing, return `404 Not Found` with `{ error: "Evidence not found" }`.
      - Enforce authorization checks:
        - If `user.role === "ADMIN"`: permit.
        - If `evidence.userId === user.id`: permit.
        - If `user.role === "INSTRUCTOR"`: call `getInstructorScope(user.id, user.name)`. Check if `evidence.userId` is present in the resolved instructor's scoped learner IDs. If so, permit.
        - Otherwise, return `403 Forbidden` with `{ error: "Forbidden" }`.
      - Read file from disk: reconstruct path using `path.join(process.cwd(), "uploads", "evidence", path.basename(evidence.fileUrl))`.
      - Stream the file using `fs.readFile` / `Response` with headers `Content-Type: evidence.fileType`.
    - Create `tests/evidence-gated-file.test.ts` covering:
      - 401/403 for missing or unauthorized session/roles.
      - 404 for non-existent evidence.
      - 200/file streaming for the uploading learner.
      - 200/file streaming for the scoped instructor.
      - 200/file streaming for admin.
  </action>
  <verify>
    <automated>npx vitest run tests/evidence-gated-file.test.ts</automated>
  </verify>
  <done>
    - `GET /api/evidence/[id]/file` is implemented with authorization checks.
    - `tests/evidence-gated-file.test.ts` passes successfully.
  </done>
</task>
