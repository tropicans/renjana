# Plan 15-01: Haversine Distance Utility

## Objective

Create `src/lib/geo.ts` with a `haversineDistance` function that calculates the great-circle distance between two GPS coordinate pairs. This utility is a dependency for Plan 15-02 (GPS validation in the attendance route handler). Unit tests verify correctness with known coordinate pairs.

## must_haves

- `haversineDistance` returns distance in kilometers between two (lat, lng) pairs
- Function handles edge cases: same point returns 0, antipodal points return ~20000 km
- Unit tests pass with `npx vitest run tests/geo.test.ts`

## truths

- D-01: Earth radius 6371 km; Monas coordinates Lat `-6.175392`, Lng `106.827153`
- D-02: Permitted radius is 500 meters = 0.5 km from target coordinates

<action>
Create `src/lib/geo.ts` with:

1. A private helper function `toRad(deg: number): number` that converts degrees to radians (`deg * Math.PI / 180`).

2. An exported named function `haversineDistance(lat1: number, lon1: number, lat2: number, lon2: number): number` that:
   - Uses Earth radius constant `R = 6371` (km)
   - Computes delta-lat and delta-lon in radians
   - Applies the Haversine formula: `a = sin²(dLat/2) + cos(lat1) * cos(lat2) * sin²(dLon/2)`
   - Computes `c = 2 * atan2(sqrt(a), sqrt(1-a))`
   - Returns `R * c` (distance in kilometers)

Follow the lib file pattern: no imports needed (pure math), private helper not exported, named export with explicit parameter types and return type `number`. File should be under 30 lines.
</action>

- `toRad` is defined but NOT exported
- File has no external imports (pure math only)
- `npx tsc --noEmit` reports no type errors for the file
</acceptance_criteria>
</task>
