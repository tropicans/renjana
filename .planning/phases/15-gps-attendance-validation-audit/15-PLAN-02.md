# Plan 15-02: GPS Validation in Attendance Route Handler + Route Tests

## Objective

Modify the `POST /api/attendance` handler to enforce GPS coordinate validation for `OFFLINE_EVENT` and `HYBRID` courses. Create comprehensive route handler tests covering all GPS validation scenarios.

## must_haves

- Missing GPS for offline/hybrid courses returns 400 with `"Akses lokasi (GPS) diperlukan untuk absensi luring"`
- GPS coordinates outside 500m of Monas returns 403 with `"Di luar jangkauan"`
- GPS coordinates within 500m of Monas allows check-in (201)
- ONLINE course check-in does NOT require GPS (201 without coordinates)
- All existing tests continue to pass
- `npm run build` succeeds

## truths

- D-01: Target coordinates Lat `-6.175392`, Lng `106.827153` (Monas)
- D-02: Permitted radius is 500 meters (0.5 km)
- D-03: Missing GPS error message is `"Akses lokasi (GPS) diperlukan untuk absensi luring"` with status 400
- D-04: Enforce for `OFFLINE_EVENT` and `HYBRID` course types (checked via `lesson.module?.course?.type`)
- Out-of-range error message is `"Di luar jangkauan"` with status 403
