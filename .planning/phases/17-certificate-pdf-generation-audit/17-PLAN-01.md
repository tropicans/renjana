<task type="auto">
  <name>Task 2: Implement gated certificate serving route and tests</name>
  <files>src/app/api/certificates/[enrollmentId]/file/route.ts, tests/certificate-gated-file.test.ts</files>
  <action>
    - Create `src/app/api/certificates/[enrollmentId]/file/route.ts` implementing a `GET` request handler.
      - Authenticate using `requireApiAuthPolicy(req, { sameOrigin: true })`. If not ok, return `policy.response`.
      - Retrieve `enrollmentId` from params.
      - Perform eligibility and authorization checks:
        - If `user.role === "ADMIN"`: call `getAdminCertificateEligibility(enrollmentId)`.
        - Otherwise, call `getCertificateEligibility(user.id, enrollmentId)`.
        - If eligibility check is not ok, return `NextResponse.json({ error: eligibility.error }, { status: eligibility.status })`.
      - Query `prisma.certificate.findUnique({ where: { enrollmentId } })`. If missing, return `404 Not Found` with `{ error: "Certificate record not found" }`.
      - Read the PDF file from disk:
        - Extract the filename using `path.basename(certificate.pdfUrl)`.
        - Construct the disk path using `path.join(process.cwd(), "uploads", "certificates", filename)`.
        - Read file via `fs.promises.readFile(filePath)`.
        - Return the file contents with headers:
          - `Content-Type: application/pdf`
          - `Content-Disposition: attachment; filename="certificate-${enrollmentId.slice(0, 8)}.pdf"`
        - Wrap in a try-catch, returning 404 with `{ error: "File not found on disk" }` on file read error.
      - Wrap route execution in `withRequestObservability`.
    - Create `tests/certificate-gated-file.test.ts` to cover:
      - 401/403 for unauthorized users.
      - 404 for non-existent certificate or enrollment.
      - 200 with attachment headers for eligible owner.
      - 200 with attachment headers for admin.
      - 404 on missing file on disk.
  </action>
  <verify>
    <automated>npx vitest run tests/certificate-gated-file.test.ts</automated>
  </verify>
  <done>
    - `GET /api/certificates/[enrollmentId]/file` is implemented and gated.
    - Test coverage in `tests/certificate-gated-file.test.ts` passes successfully.
  </done>
</task>
