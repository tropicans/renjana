  <files>src/lib/certificate-service.ts, src/app/api/admin/certificates/[enrollmentId]/route.ts</files>
  <action>
    - Modify `src/lib/certificate-service.ts` to change `prisma.certificate.create` to `prisma.certificate.upsert` (per D-05 rationale):
      - Query search criteria: `where: { enrollmentId: input.enrollmentId }`.
      - Update fields: `pdfUrl, issuedAt: new Date()`.
      - Create fields: `enrollmentId, userId, pdfUrl`.
    - Modify `src/app/api/admin/certificates/[enrollmentId]/route.ts`:
      - Parse query params: check if `new URL(req.url).searchParams.get("force") === "true"`.
      - Locate the block checking `enrollment.certificate`.
      - If `enrollment.certificate` exists:
        - If `force` is true:
          - Extract filename using `path.basename(enrollment.certificate.pdfUrl)`.
          - Construct file path using `path.join(process.cwd(), "uploads", "certificates", filename)`.
          - Import `unlink` from `fs/promises` and call `await unlink(filePath)` inside a try-catch to delete the old file.
          - Call `generateCertificateRecord` to overwrite/regenerate.
          - Write security audit log `writeSecurityAuditLog(prisma, { userId: user.id, action: "REGENERATE_CERTIFICATE", entity: "CERTIFICATE", entityId: enrollment.certificate.id, metadata: { enrollmentId } })`.
          - Return the new certificate in a `200 OK` or `201 Created` response.
        - If `force` is not true:
          - Return existing certificate `NextResponse.json({ certificate: enrollment.certificate })`.
  </action>

  </verify>
