<threat_model>
- Unauthorized Access: The dashboard leverages requireAuth and fetches data from secured backend APIs (/api/courses/[id] and /api/progress/[enrollmentId]), maintaining the access gating constraints.
- Invalid Date Handling: Using invalid or null completedAt timestamps could cause runtime crashes; formatted date calculations implement fallback safeguards to enrolledAt.
- Division by Zero: Courses with zero modules or zero lessons are handled gracefully without causing rendering crashes.
</threat_model>

<success_criteria>

- Only the module containing the 'Up Next' lesson is expanded by default; clicking other module headers collapses/expands them.
